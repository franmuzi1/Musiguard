ANTIVIRUS DIY (MusiGuard) — versione per MARCO
==============================================

COS'È E COME FUNZIONA (leggi prima di installare)
-------------------------------------------------
Il browser scarica tutto in una cartella "quarantena" (~/PreDownload) che
vive su un disco virtuale separato, montato in modo che NULLA possa essere
eseguito da lì (noexec). Un servizio in background (il "guardiano") nota
ogni nuovo file e lo controlla:

  1. Tipo reale del file (MIME): se un file finge di essere una foto ma
     dentro è un programma eseguibile, viene segnalato.
  2. Scansione antivirus con ClamAV.

Se il file è pulito → viene spostato automaticamente in ~/Downloads e ti
arriva una notifica. Se è sospetto → si apre una finestra con tre scelte:
Elimina / Lascia isolato in quarantena / Ignora il rischio e sposta comunque.
Se non scegli nulla, il file resta in quarantena: male non fa.

IMPORTANTE:
- Imposta il browser per scaricare in ~/PreDownload (Impostazioni →
  Download), altrimenti il guardiano non vede niente.
- NON spostare e NON cestinare mai il file ~/pre_download_disk.img:
  è il disco della quarantena.
- Il disco è "elastico": occupa 50GB virtuali ma sul disco vero solo lo
  spazio dei file davvero presenti in quarantena.

INSTALLAZIONE
-------------
# 0. Scarica il repo (se non l'hai già fatto)
git clone https://github.com/muzi1837278-cell/My_dot_File.git ~/I-Miei-Dotfiles

# 1. Dipendenze
sudo apt update && sudo apt install -y inotify-tools zenity clamav libnotify-bin

# 2. Cartella quarantena e disco elastico da 50GB
mkdir -p ~/PreDownload
truncate -s 50G ~/pre_download_disk.img
/sbin/mkfs.ext4 -F ~/pre_download_disk.img

# 3. Montaggio sicuro: noexec/nosuid/nodev (niente esecuzione dalla
# quarantena), nofail (se l'immagine manca il boot NON si blocca)
sudo sed -i '\|pre_download_disk.img|d' /etc/fstab
echo "$HOME/pre_download_disk.img $HOME/PreDownload ext4 loop,rw,nofail,noexec,nosuid,nodev,data=ordered,errors=remount-ro,discard 0 2" | sudo tee -a /etc/fstab > /dev/null
sudo systemctl daemon-reload
sudo mount ~/PreDownload
sudo chown $USER:$USER ~/PreDownload

# 4. Installa gli script
mkdir -p ~/MusiGuard
cp ~/I-Miei-Dotfiles/MusiGuard/AntiVirusDIY.sh ~/I-Miei-Dotfiles/MusiGuard/guardiano-download.sh ~/MusiGuard/
chmod +x ~/MusiGuard/*.sh

# 5. Configurazione "semplice" (questa è la differenza con la versione
# completa): niente smistamento per tipo, niente domanda sul codice SHA256.
# Tutto ciò che è pulito finisce dritto in ~/Downloads.
mkdir -p ~/.config
printf 'SMISTAMENTO=0\nCHIEDI_SHA=0\n' > ~/.config/musiguard.conf

# 6. Servizio automatico (parte da solo a ogni accensione)
mkdir -p ~/.config/systemd/user
cp ~/I-Miei-Dotfiles/.config/systemd/user/guardiano.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now guardiano.service

echo "[✓] Fatto! Scarica un file di prova col browser e guarda la notifica."

FUNZIONI EXTRA (spente di default, attivale solo se le vuoi)
------------------------------------------------------------
- Smistamento automatico per tipo (foto in Pictures/Downloads, video in
  Videos/Downloads, documenti in Documents/Downloads, ecc.):
  metti SMISTAMENTO=1 in ~/.config/musiguard.conf

- Verifica manuale del codice SHA256 (a ogni download si apre una finestra
  dove incollare l'impronta pubblicata dal sito, utile per ISO e programmi):
  metti CHIEDI_SHA=1 in ~/.config/musiguard.conf

- Pulizia automatica (ATTENZIONE: cestina i file più vecchi di 7 giorni in
  ~/Downloads e svuota il cestino il 1° del mese — installala solo se sai
  che la vuoi):
  sudo apt install -y trash-cli
  cp ~/I-Miei-Dotfiles/MusiGuard/pulizia-automatica.sh ~/MusiGuard/ && chmod +x ~/MusiGuard/pulizia-automatica.sh
  cp ~/I-Miei-Dotfiles/.config/systemd/user/pulizia.service ~/.config/systemd/user/
  cp ~/I-Miei-Dotfiles/.config/systemd/user/pulizia.timer ~/.config/systemd/user/
  systemctl --user daemon-reload && systemctl --user enable --now pulizia.timer

PROBLEMI?
---------
- "Il guardiano non fa niente": controlla che il browser scarichi davvero
  in ~/PreDownload e che il servizio giri:  systemctl --user status guardiano
- Log:  journalctl --user -u guardiano -n 30
